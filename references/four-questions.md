# 四问自助模板

这是文章原文附带的一段改写提示词，用户可以不经过本技能、直接复制使用。技能在改写前回答的也是同样四个问题。

## 模板原文（可直接复制）

```text
我要这个任务更深的版本，不是更大的版本。在动手改写之前，先回答我四个问题：
一、这个领域的顶尖专家在这里会做什么，而我没有要求的。
二、他们会从什么最原始的材料开始，而不是已经被消化过的二手信息。
三、他们会用什么具体的专业方法和工具？
四、除了你和我之外，什么外部标准能证明这个结果是对的？
回答完之后，把我的提示词改写成正好要这些。

我的提示词是：
（把原始需求贴在这里）
```

## 每一问在改什么

| 问题 | 对应维度 | 它逼出了什么 |
|---|---|---|
| 一、顶尖专家会做什么，而我没有要求的 | 高度 | 被任务描述遮住的更高目标 |
| 二、从什么最原始的材料开始 | 深度 | 材料来源：原始日志、数据库、一手记录，替代二手汇总 |
| 三、用什么专业方法和工具 | 深度 | 具体工具与方法的指定，替代「扮演专家」 |
| 四、什么外部标准能证明结果是对的 | 深度 | 外部裁判条款，杜绝模型自评自审 |

广度维度的名词换动词不在四问里，使用时可以在模板前面加一句：

```text
先把我这个需求里的名词换成动词：这个产物存在的目的，是要让谁在什么条件下做出什么决定？
```

## 使用方法

1. 把模板整体复制给任意大模型，末尾贴上你的原始需求；
2. 先看它对四问的回答——如果四问都答得空泛，说明这个需求本身信息不足，先补背景再继续；
3. 确认四问回答合理后，再让它输出改写结果；
4. 拿到改写结果后，对照 `anti-patterns.md` 检查一遍，重点看有没有退回「扮演 XX 专家」的写法。

## 填写示例

原始需求：

> 帮我分析一下用户流失的原因。

四问回答（节选）：

> 一、顶尖的增长分析师不会停在「分析原因」，会定位到最早的可行动流失信号，并给出干预方案的验证设计。
> 二、从用户行为事件表的原始埋点日志开始，而不是行业报告里的流失率汇总。
> 三、用 Python 对事件流做生存分析和分群对比，写 SQL 直接查数，不凭印象推断。
> 四、用最近一个月、模型没见过的用户数据回测：预测出的流失用户与实际流失的重合度。

改写结果（节选）：

> 连接用户行为事件表，从原始埋点日志开始（不要用汇总报表），用 Python 做生存分析和分群对比，找出最早的三个流失信号；在最近一个月的数据上回测信号有效性，输出信号命中率的真实数字；结论必须附带可复现的查询脚本。
